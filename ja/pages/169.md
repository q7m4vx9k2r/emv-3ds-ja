### 5.9.13 ACSによるRResのエラー処理：03-3RI

ACSは、RResまたはErrorメッセージの検証を次のとおり処理する。以下のErrorメッセージはA.9節で定義する。

- 認識できないメッセージの場合、DSにError Component = A、Error Code = 101を返す。
- RResの場合、表B.9と5.1.7節に従って検証する。存在するデータ要素が検証に失敗した場合、DSにError Component = A、Error Code = 203を返す。必須データ要素が欠ける場合、DSにError Component = A、Error Code = 201を返す。それ以外ではメッセージにエラーはない。

### 5.10 UTCの日付と時刻

本節では、3DS構成要素によるUTC日付・時刻の取扱い要件を示す。

**Seq 5.114 [Req 416]** UTC日付・時刻のデータ要素を提供または検証するとき、3DS Server、DS、ACSのUTCとの最大の時刻ずれは15分未満でなければならない。

SDK Signature TimestampまたはPurchase Date & Timeを、UTCとの時刻差が30分を超える状態で受信した場合、DSは3DS ServerにError Component = D、Error Code = 203のErrorメッセージ（A.9節で定義）を返さなければならない。

**Seq 5.115 [Req 417]** SDK Signature TimestampまたはPurchase Date & Timeを、UTCとの時刻差が30分を超える状態で受信した場合、ACSはDSにError Component = A、Error Code = 203のErrorメッセージ（A.9節で定義）を返してもよい。
