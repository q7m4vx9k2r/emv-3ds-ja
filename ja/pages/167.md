### 5.9.10 DSによるRResのエラー処理

DSは、RResまたはErrorメッセージの検証を次のとおり処理する。以下のErrorメッセージはA.9節で定義する。

認識できないメッセージの場合：

- 3DS ServerにError Component = D、Error Code = 101を返す。
- 特定の取引を識別できる場合、アプリ方式は[Req 63]、ブラウザ方式は[Req 125]、3RIは[Req 350]のセキュアな接続で、ACSにError Component = D、Error Code = 101を送る。

RResの場合、表B.9と5.1.7節に従って検証する。

- 存在するデータ要素が検証に失敗した場合、3DS ServerにError Component = D、Error Code = 203を返す。特定の取引を識別できれば、アプリ方式は[Req 63]、ブラウザ方式は[Req 125]、3RIは[Req 350]のセキュアな接続で、ACSにError Component = D、Error Code = 203を送る。
- 必須データ要素が欠ける場合、3DS ServerにError Component = D、Error Code = 201を返す。特定の取引を識別できれば、アプリ方式は[Req 63]、ブラウザ方式は[Req 125]、3RIは[Req 350]のセキュアな接続で、ACSにError Component = D、Error Code = 201を送る。
- それ以外ではメッセージにエラーはない。

Errorメッセージの場合、特定の取引を識別できれば、アプリ方式は[Req 63]、ブラウザ方式は[Req 125]、3RIは[Req 350]のセキュアな接続で、3DS Serverから受信したErrorメッセージをACSに送る。

最後に、DSの規則に従って必要な取引情報をログに記録する。

### 5.9.11 ACSによるRResのエラー処理：01-APP

ACSは、RResまたはErrorメッセージの検証を次のとおり処理する。

認識できないメッセージの場合：

- DSに、Error Component = A、Error Code = 101のErrorメッセージ（A.9節で定義）を返す。
- 特定の取引を識別でき、Decoupled Authentication取引でない場合、次ページの処理を行う。
