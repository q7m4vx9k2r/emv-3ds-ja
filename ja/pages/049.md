## 3 EMV 3-D Secure認証フローの要件

本章では、EMV 3-D Secure処理フローの要件を定める。明確化のため、3-D Secure認証処理に関与するすべての構成要素の動作を説明するが、本コア仕様が対象とするのは次の4つである。

- 3DS Client（3DS SDK、3DS Method）
- 3DS Server
- Directory Server（DS）
- Access Control Server（ACS）

各構成要素は、記載どおりに仕様に従わなければならない。アプリ方式のモデルについては、詳細な要件と実装ガイドラインを定める、適用される3DS SDK仕様も参照すること。

第2章で紹介したとおり、チャレンジフローの初期処理はフリクションレスフローと同じである。そのため本章では、両方のフローを1つの処理フローとして説明する。

注：本章を通じて使用する「検証（Validate）」は、3-D Secure構成要素が受信メッセージを検証する要件を指す。実際の検証処理の詳細は5.9節の該当する小節で定義する。検証処理には、表A.1のデータ要素と5.1.6節の機能に基づく、各データ要素の有無および形式の確認が含まれ、メッセージにエラーがある場合の実際のエラー処理も含まれる。また、メッセージの暗号学的検証や復号を含めてもよい。
