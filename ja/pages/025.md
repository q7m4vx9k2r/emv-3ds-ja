### 表1.3：定義（続き）

| 用語 | 定義 |
| --- | --- |
| Directory Server（DS） | 相互運用ドメインで動作するサーバー。3DS Serverの認証、3DS ServerとACS間のメッセージルーティング、3DS Server・3DS SDK・3DS Requestorの検証などを行う。 |
| Directory Server Certificate Authority（DS CA） | 相互運用ドメインで動作し、3-D Secure参加コンポーネント向けに特定のデジタル証明書を生成・配布する。通常、DSが接続する決済システムが運営する。 |
| Directory Server ID（directoryServerID） | 決済システムに固有のRegistered Application Provider Identifier（RID）。RIDはISO 7816-5で定義される。Directory Server IDは、16進値を10文字のテキストとして符号化する。例：`0x'A000000003'` は `'A000000003'` となる。 |
| Electronic Commerce Indicator（ECI） | カード会員認証の試行結果を示すためACSが提供する、決済システム固有の値。 |
| Empty（空） | フィールド名が存在し、値が空の要素。下のJSONでは `firstName` にデータがない。 |
| EMV | 安全な決済取引の世界的な相互運用・受け入れのためのEMVCo仕様、またはそれに準拠する製品・サービスを指す。 |
| EMV Payment Token | EMVトークン化仕様で定義されるPANの代替値。指定のToken BIN・Token BIN範囲から発行する、ISO/IEC 7812に準拠した可変長の数値で、関連する全BIN表に適切に表示する。Luhnチェックを含むアカウント番号の基本検証に合格する。PANと同じ値にはならず、PANと競合しない。 |
| EMVCo | 米国デラウェア州で設立された有限責任会社EMVCo, LLC。 |
| Ends 3-D Secure Processing | 本仕様に定義された以後の処理を行わないこと。加盟店の意向により、3-D Secure認証が成功していなくても承認取引を実行する場合がある。 |

```json
  "lastName": "Smith"
}
```
