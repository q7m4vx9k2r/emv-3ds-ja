### 表1.3：定義（続き）

| 用語 | 定義 |
| --- | --- |
| Missing（欠落） | 名前・値の組がない（Absent）場合、またはフィールド名があり値が空の場合。下の2つのJSONのどちらでも `firstName` にデータがない。 |
| Name/value Pair（NVP） | 属性・値の組をカプセル化する単純なクラス。 |
| Native（ネイティブ） | デバイス自身のAPIを使う、本来の表示方法を指す。 |
| Null | フィールド名が存在し、値がnullの要素。下のnullの例を参照。 |
| One-Time Passcode（OTP） | コンピューターなどのデジタル機器で、1回のログインセッション・取引にのみ有効なパスコード。 |
| Out-of-Band（OOB） | 3-D Secureフローの外で、並行して完了するチャレンジ活動。最終CReqは、ACSが確認するデータを運ぶのではなく、認証完了だけを示す。ACSの認証方法・実装は3-D Secure仕様で定義しない。 |
| OOB Authentication App | 3-D Secureフローの一部としてACSがカード会員を認証するため使用するデバイス上のアプリ。例はモバイル銀行アプリ。OOBフローは3.2節参照。 |
| Operation Request（OReq）Message | アラート、リマインダー、報告、対応要請としての運用情報を伝えるため作るメッセージシーケンス。3-D Secure認証メッセージフローの一部ではない。 |
| Operation Response（ORes）Message | OReqシーケンスの受領を確認する。OReq受信者が生成し、OReq送信元に返す。 |
| Payment System（決済システム） | 運用ルール・条件、およびカード発行・加盟店受け入れの要件を定める。 |

フィールド名が存在し、値が空の例：

```json
{"firstName":"", "lastName":"Smith"}
```

名前・値の組が存在しない例：

```json
{"lastName":"Smith"}
```

nullの例：

```json
{"firstName":null, "lastName":"Smith"}
```
