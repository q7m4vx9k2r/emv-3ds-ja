#### 手順3：DS

DSは、次を実施しなければならない。

**Seq 3.203 [Req 278]** 3DS ServerからAReqを受信し、5.9.1節で定義するとおりに検証する。

メッセージにエラーがある場合、DSは処理を終了する。

**Seq 3.204 [Req 279]** DS Transaction IDを生成する。

**Seq 3.205 [Req 280]** DSとACSがMessage Version Numberに対応していることを確認する。

対応していない場合、DSは3DS Serverに次のいずれかを返し、処理を終了する。

- 個々のDSが定義する適切な応答をTransaction Statusに設定したARes（表B.2で定義）。
- Error Component = D、Error Code = 102のErrorメッセージ（A.9節で定義）。

**Seq 3.206 [Req 281]** AReqのデータ要素をさらに次のとおり確認する。

- 3DS Server Reference Numberが参加する3DS Serverを表していない場合、DSは3DS Serverに、Error Component = D、Error Code = 303のErrorメッセージ（A.9節で定義）を返し、処理を終了する。
- Merchant Category Code（MCC）が当該DSで有効でない場合、DSは3DS Serverに、Error Component = D、Error Code = 306のErrorメッセージ（A.9節で定義）を返し、処理を終了する。

**Seq 3.207 [Req 282]** AReqで受信したCardholder Account Numberが、参加するアカウント範囲に含まれるかを判定する。
