## 1.9 用語と表記規則

| 用語 | 本仕様での意味 |
| --- | --- |
| Shall | 必須の製品・システム能力。「～しなければならない」と訳す。 |
| May | 任意の製品・システム能力、または参考情報だけで本仕様の範囲外の記述。 |
| Should | 推奨する製品・システム能力。「～するべきである」と訳す。 |
| End(s) 3-D Secure Processing | 第3章の認証フローで、以後の処理が仕様の範囲外になる特定の例外状態。表1.3も参照。 |
| End(s) Processing | 第3章の認証フローで、コンポーネントにエラーが起き、正常処理しない特定の例外状態。後続コンポーネントがそのエラーに対応する。表1.3も参照。 |
| Increment(s) | カウンターを1増やすこと。コンポーネントに増加が要求される場合がある。 |

### 3DS SDK

EMVCoは、3DS SDKの実装を2種類定義しています。

1. Default SDK：3DS Requestor Appに統合するSDKとして設計したソフトウェアコンポーネント。『EMV 3-D Secure—SDK Specification』で定義され、同文書では3DS SDKと呼ばれます。本コア仕様書の旧版でも3DS SDKと呼ばれていました。
