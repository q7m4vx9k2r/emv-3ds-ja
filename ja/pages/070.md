# PDF 70ページ — 日本語参考訳

> 非公式の日本語参考訳。原本のページ単位で対応しています。全文翻訳は未完了です。図内の文字は英語原文のままです。

[目次](../../index.md) · [英語原文](../../en/pages/070.md) · [前ページ](./069.md) · [次ページ](./071.md)

3DS Requestor Environment（2.6.2節で概説）によっては、追加情報を取得してもよい。3DS Requestorは、Cardholder Account Numberおよび任意のその他のカード会員情報を使い、そのカード範囲のACS Protocol Version一覧、DS Protocol Version一覧、および存在する場合は3DS Method URLを3DS Serverに要求する。

3DS Serverは、次を実施しなければならない。

**Seq 3.113 [Req 80]** カード範囲に対するACS Protocol Version一覧、DS Protocol Version一覧、および存在する場合は3DS Method URLを取得する。これらは以前に受信したPResから保存されたものである。

**Seq 3.114 [Req 81]** 3DS Server Transaction IDを生成する。

**Seq 3.115 [Req 82]** 3DS Server Transaction ID、ACS Protocol Versions、DS Protocol Versions、および存在する場合は3DS Method URLを、3DS Requestor Environmentを通じて3DS Requestorに返す。

カード範囲にDS Protocol Versionsがない場合、PRes内のDS Protocol Versionsの既定値を使用しなければならない。

#### 手順3：3DS Requestor Environment

3DS Serverは、次を実施しなければならない。

**Seq 3.116 [Req 83]** 各取引で、3DS RequestorのWebサイトの3DS Methodに使用する3DS Server Transaction IDと、AReqに使用する3DS Server Transaction IDが同じであることを確実にする。

**Seq 3.117 [Req 84]** 3DS Method URLがある場合、5.8.1節で定義するとおりに3DS RequestorのWebサイト上で3DS Methodが実行されることを確実にする。

#### 手順4：ブラウザとACS

手順2の3DS Serverからの応答に3DS Method URLがあった場合、ブラウザは3DS Methodを介してACS、またはACSが指定する主体に接続し、ブラウザ情報と端末情報を収集する。3DS Methodによる端末情報の取得方法と収集する情報は、本仕様の対象外である。ただし、後でACSにおいて照合できるように、3DS Server Transaction IDを使ってブラウザ／端末情報を識別する必要がある。メッセージ処理の詳細は第5章を参照すること。

ACSまたはACSが指定する主体による端末情報の取得・利用方法は、本仕様の対象外である。ただし、ブラウザがセキュアな接続（6.1.8節で定義）を使ってACSに接続することは必須である。

ACSは、次を実施しなければならない。

**Seq 3.118 [Req 85]** ブラウザとACSの間の通信が、サーバ認証を行うTLSセッション（6.1.8節で定義）を使って確立されることを確実にする。

要求どおりに通信を確立できない場合、ACSは処理を終了する。

注：3DS Methodの要件は5.8.1節で定義する。

#### 手順5：3DS Requestor Environment

3DS Requestor Environmentは、3DS Serverが組み立てるAReqの情報を収集する責任を持つ。
