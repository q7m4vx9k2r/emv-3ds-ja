# PDF 91ページ — 日本語参考訳

> 非公式の日本語参考訳。原本のページ単位で対応しています。全文翻訳は未完了です。図内の文字は英語原文のままです。

#### 手順10：3DS Server

3DS Serverは、次を実施しなければならない。

**Seq 3.249 [Req 443]** Transaction Status = S（3DS Requestorが実施するSPC認証）の場合、次を実施する。

a. AResから必要な情報（表B.2で定義）、特にWebAuthn Credential listとSPC Transaction Dataを、3DS Requestor Environmentに送信する。

b. 手順10aに進む。

#### 手順10a：3DS Requestor

3DS Requestorは、AResで返されたWebAuthn Credential listを対象にSPC認証（SPC API）を呼び出し、SPC Transaction Dataを提供する。

**Seq 3.250 [Req 450]** 3DS Requestorは、SPC認証のために3DS Serverから受信したデータを変更または保存してはならない。

#### 手順10b：カード会員

カード会員が、自身の端末のFIDO Authenticatorを使って認証する。

#### 手順10c：3DS Requestor

3DS Requestorは、SPC API呼出しからAssertion Dataを取得する。

#### 手順10d：3DS Requestor

3DS Requestorは、Assertion DataをACSに返すため、2回目の3DS Authentication Requestを開始する。AReq処理中は、4.3.1.1節で定義する処理中画面を表示する。

#### 手順10e：3DS Server

3DS Serverは、FIDO Assertion Dataを含む2回目のAReqを送信する。本手順では、ブラウザフローの手順6の要件に加え、次を実施しなければならない。

**Seq 3.251 [Req 444]** AReqに次を含める。

a. 新しい3DS Server Transaction ID。

b. FIDO Authenticatorが生成したAssertion Data。3DS Requestor Authentication Method = 09を使って3DS Requestor Authentication Dataに含める。

c. 次の内容を持つ3DS Requestor Prior Transaction Authentication Informationオブジェクト。

- 3DS Requestor Prior Transaction Reference：SPC認証の実施を示すAResのACS Transaction ID。
- 3DS Requestor Prior Transaction Authentication Method = 05（SPC認証）。
- 3DS Requestor Prior Transaction Authentication Timestamp。

注：ブラウザ方式の手順6で[Req 87]と[Req 88]を実行する際に収集するデータは、最初のAReqの情報と同じである。
