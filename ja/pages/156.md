# PDF 156ページ — 日本語参考訳

> 非公式の日本語参考訳。原本のページ単位で対応しています。全文翻訳は未完了です。図内の文字は英語原文のままです。

[Req 303]の続き：

- 必須データ要素が欠けている場合：Error Code = 201。
- Serial Numberが無効な場合：Error Code = 307。
- 3DS Serverが1時間以内に複数のCard Range Data要求を送信した場合：Error Code = 103。

**Seq 5.85 [Req 457]** Card Range Data Fileのダウンロードについて、RFC 7233で定義するRange Requestsに対応する。

**Seq 5.86 [Req 458]** Card Range Dataに含まれるカード範囲の開始・終了について、重複や競合がないことを確実にする。

**Seq 5.87 [Req 459]** Card Range Dataには、EMV 3-D Secureに参加し、要求に応答するDSに登録されたカード範囲の情報だけを提供する。

**Seq 5.88 [Req 460]** DSが対応し、PReqにCard Range Data Download Indicatorがあった場合、Card Range Data Fileを準備する。このファイルには、参加するカード範囲の全一覧を含める。例えばCard Range DataのJSONオブジェクト`{"cardRangeData": [... ]}`である。

**Seq 5.89 [Req 426]** PResを準備し、次のいずれかで応答する。

- 圧縮された応答本文と、gzipを使用したことを示す`Content-Encoding: gzip`ヘッダー。
- 非圧縮の応答本文。PResでCard Range Data File URLを提供する場合、DSは非圧縮形式を使用しなければならない。

**Seq 5.90 [Req 250]** 表A.1のCard Range Dataで定義するDSのカード範囲情報、または対応する場合はCard Range Data File URLを含むPResを送信する。

PReqにSerial Numberがない場合、またはDSがキャッシュの部分更新に対応しない場合、PResは、Action Indicator = Aのみを使い、Card Range Dataに参加するカード範囲の全一覧を含めなければならない。

3DS Serverは、次を実施しなければならない。

**Seq 5.91 [Req 304]** PResを受信し、表B.7に従って検証する。

- 存在するデータ要素が検証に失敗した場合、Error Component = S、Error Code = 203のErrorメッセージ（A.9節で定義）をDSに返す。
- 必須データ要素が欠けている場合、Error Component = S、Error Code = 201のErrorメッセージ（A.9節で定義）をDSに返す。

3DS ServerはPRes、またはCard Range Data File URLからダウンロードしたファイルからCard Range Dataを取得する。ファイルダウンロードでは、3DS ServerとDSが圧縮形式（HTTP要求の`Accept-Encoding: gzip`）に対応することを推奨する。

**Seq 5.92 [Req 385]** Action Indicatorに従い、各Card Range Dataのキャッシュ情報を更新する。データにエラーがある場合の処理は次ページに続く。
