[Req 56]のセキュアな接続で、3DS SDKにError Component = A、Error Code = 101のErrorメッセージ（A.9節で定義）を送る。

RResの場合、ACSは表B.9と5.1.7節に従って検証する。

- 存在するデータ要素が検証に失敗した場合、DSにError Component = A、Error Code = 203のErrorメッセージ（A.9節で定義）を返す。特定の取引を識別でき、Decoupled Authentication取引でなければ、[Req 56]の接続で3DS SDKにError Component = A、Error Code = 203のErrorメッセージ（A.9節で定義）を送る。
- 必須データ要素が欠ける場合、DSにError Component = A、Error Code = 201のErrorメッセージ（A.9節で定義）を返す。特定の取引を識別でき、Decoupled Authentication取引でなければ、[Req 56]の接続で3DS SDKにError Component = A、Error Code = 201のErrorメッセージ（A.9節で定義）を送る。
- それ以外ではRResにエラーはない。注：CResのTransaction Statusは、ACSが3.1節の手順17で判定したものである。

Errorメッセージの場合、特定の取引を識別でき、Decoupled Authentication取引でなければ、[Req 56]の接続で3DS SDKにError Component = A、Error Code = 403のErrorメッセージ（A.9節で定義）を送る。

### 5.9.12 ACSによるRResのエラー処理：02-BRW

ACSは、RResまたはErrorメッセージの検証を次のとおり処理する。

- 認識できないメッセージの場合、DSにError Component = A、Error Code = 101のErrorメッセージ（A.9節で定義）を返す。特定の取引を識別でき、Decoupled Authentication取引でなければ、ブラウザ経由で3DS ServerにCResを送る。
- RResの場合、表B.9と5.1.7節に従って検証する。存在するデータ要素が検証に失敗した場合、DSにError Component = A、Error Code = 203のErrorメッセージ（A.9節で定義）を返す。特定の取引を識別でき、Decoupled Authentication取引でなければ、ブラウザ経由で3DS ServerにCResを送る。
- 必須データ要素が欠ける場合の処理は次ページに続く。
