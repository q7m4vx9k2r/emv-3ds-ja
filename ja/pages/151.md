# PDF 151ページ — 日本語参考訳

> 非公式の日本語参考訳。原本のページ単位で対応しています。全文翻訳は未完了です。図内の文字は英語原文のままです。

[目次](../../index.md) · [英語原文](../../en/pages/151.md) · [前ページ](./150.md) · [次ページ](./152.md)

**Seq 5.47 [Req 221]** 30秒のタイムアウトが満了し、その取引についてDSからErrorメッセージを受信していない場合、Transaction Status = N、Transaction Status Reason = 14（ACSで取引がタイムアウト）、Challenge Cancelation Indicator = 05（ACSで取引がタイムアウト―最初のCReq未受信）のRReqをDSに送信する。現在の取引のCReq／CRes交換用に生成・保存した一時鍵を消去する。

**Seq 5.48 [Req 222]** タイムアウト済み取引のCReqを受信した場合、Error Component = A、Error Code = 402のErrorメッセージ（A.9節で定義）を、アプリ方式では3DS SDKに、ブラウザ方式では3DS Requestorに送信する。

アプリ方式では、ACSと3DS SDKの最初のCReq／CRes交換で取引を確立した後、カード会員のチャレンジの継続・完了に追加のCReqが必要なCRes（Challenge Completion Indicator = N）を送信するとき、ACSは次を実施しなければならない。

**Seq 5.49 [Req 223]** 各CResを3DS SDKに正常送信した後、タイムアウトを10分（600秒）に設定する。

**Seq 5.50 [Req 224]** 次のCReqの受信前にタイムアウトが満了した場合、60秒以内に、Transaction Status = N、Transaction Status Reason = 14（ACSで取引がタイムアウト）、Challenge Cancelation Indicator = 04のRReqを、3DS Serverに渡すためDSに送信する。その後、この取引のCReq／CRes交換用に生成・保存した一時鍵をすべて消去する。

**Seq 5.51 [Req 225]** タイムアウト済み取引のCReqを受信した場合、Error Component = A、Error Code = 402のErrorメッセージ（A.9節で定義）を3DS SDKに送信する。

ブラウザ方式では、3DS RequestorからACSへのCReq POSTが成功して取引を確立した後、チャレンジ用iframeにインターフェースを送信するとき、ACSは次を実施しなければならない。

**Seq 5.52 [Req 226]** 各チャレンジ用インターフェースをiframeに正常送信した後、タイムアウトを10分（600秒）に設定する。

**Seq 5.53 [Req 227]** カード会員認証の完了前にタイムアウトが満了した場合、60秒以内に、Transaction Status = N、Transaction Status Reason = 14のRReqを、3DS Serverに渡すためDSに送信する。

これによりACSのチャレンジは完了する。タイムアウト時、3DS ServerはRReq／RResについて3.3節の手順18に従う。その終了時に3DS Requestorへタイムアウトを通知する。通知方法は本仕様の対象外である。

通知を受けた3DS Requestorは、次を実施しなければならない。

**Seq 5.54 [Req 344]** 親ページを再読込みし、HTML iframeを除去してチャレンジ用iframeを閉じる。

SPCチャレンジ（Transaction Status = S）では、ACSは次を実施しなければならない。

**Seq 5.55 [Req 452]** 最初のARes送信後、タイムアウトを10分（600秒）に設定する。
