### 表1.3：定義（続き）

| 用語 | 定義 |
| --- | --- |
| Ends processing | 特定のコンポーネントがエラーを発見し、A.9節の適切なError Message、または表B.8のRReqで報告すること。そのコンポーネントは、誤ったメッセージの送信元に報告し、他のコンポーネントにも通知する場合があり、以後の3-D Secure処理を停止する。後続コンポーネントは、エラー状態を終結するため受信メッセージをさらに処理し、Error Messageを使用する。RReqの送信元は、処理停止前にRResの受信を待つべきである。 |
| FIDO Authenticator | FIDO Allianceの要件を満たし、関連メタデータを持つ認証主体。ユーザー検証と、依拠当事者の認証に必要な暗号資材の維持を担う。詳細：https://fidoalliance.org |
| Frictionless | カード会員との対話なしで認証を達成するプロセス。 |
| Frictionless Flow（フリクションレスフロー） | 2.5.1節で定義される、カード会員との対話を伴わない3-D Secureフロー。 |
| Fully Qualified URL（完全修飾URL） | Web資源の所在に必要な全情報を含む。WHATWGの定義するスキーム `https` のAbsolute-URL stringで、url-code-pointsを用いてUTF-8で符号化する。認証情報を含めない。例：`https://server.domainname.com/acs/auth%20(*ret`。定義：https://url.spec.whatwg.org/#absolute-url-string 、文字：https://url.spec.whatwg.org/#url-code-points 、認証情報：https://url.spec.whatwg.org/#include-credentials 。https://whatwg.org/ も参照。 |
| iframe | inline frameの略。フレーム内のフレームで、他の情報源のHTMLコンテンツを文書に埋め込む。参照：https://www.w3.org/html/wg/spec/the-iframe-element.html#the-iframe-element または https://html.spec.whatwg.org/#the-iframe-element |
| Information Only | 情報提供だけのデータであるためチャレンジを行わないという3DS Requestorの希望を、ACSが認識したことを示すTransaction Statusの値。 |
