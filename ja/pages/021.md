## 1.5 定義

本仕様では、次の用語を使用します。

### 表1.3：定義

| 用語 | 定義 |
| --- | --- |
| 3DS Client | EMV 3-D Secureプロトコルを開始するため、コンシューマーが3DS Requestorとやり取りできる、コンシューマー向けコンポーネント。 |
| 3DS Integrator | 3DS Requestor Environmentの構築・統合を支援し、任意で加盟店とアクワイアラーの統合も支援するEMV 3-D Secure参加者。 |
| 3DS Method | 3DS Integratorが提供し、3DS Requestor Websiteに配置するスクリプト呼び出し。リスクに基づく判断を支援する追加のブラウザー情報を取得するため、任意で使用する。 |
| 3DS Requestor | EMV 3-D Secure認証要求の開始者。例えば、購入フロー中に認証を要求する加盟店・デジタルウォレット。 |
| 3DS Requestor App | 3DS SDKを使用して3-D Secure取引を処理できる、コンシューマーデバイス上のアプリ。SDKとの統合により機能を有効にする。 |
| 3DS Requestor Environment | 3DS Requestorが管理するコンポーネント（3DS Requestor App、3DS SDK、3DS Server）。通常3DS Integratorが支援する。実装はIntegratorの定義によって異なる。 |
| 3DS Requestor Initiated（3RI） | アカウントが引き続き有効かの確認、またはカード会員認証のため、3DS Requestorが開始する3-D Secure取引。主な第1の用途は継続取引（テレビのサブスクリプション、公共料金など）。加盟店が各請求の認証データを取得する決済取引、または利用者に有効な支払手段があるかを確認する非決済取引を行いたい場合。第2の用途は、Requestorがカード会員の認証手段として分離認証を要求する場合。 |
| 3DS Requestor Website | 保存済み、またはカード会員が入力する認証情報を要求するWebサイトを提供するコンポーネント。 |
| 3DS SDK | 3DS Requestor Appとやり取りし、3DS Serverに代わって3-D Secure関連の機能を実行するコンポーネント。 |
| 3DS Server | オンライン取引を処理し、3DS RequestorとDS間の通信を支援する3DS Integratorのサーバー・システム。 |
| 3-D Secure（3DS） | 決済、非決済、アカウント確認のカード取引を安全に処理するための電子商取引認証プロトコル。 |
