### 表1.3：定義（続き）

| 用語 | 定義 |
| --- | --- |
| Platform Provider | OSやハードウェアからなるデジタルエコシステムを提供する事業体。ユーザーID・ハードウェア由来の機器IDでコンシューマーと機器を一意に識別し、リスク評価・不正防止のため共有できる。 |
| Preparation Request（PReq）Message | 3DS ServerがDSへ送り、DSのカード番号範囲に対応するACS・DSのProtocol Versionと、任意の3DS Method URLを要求し、内部保存情報を更新するメッセージ。 |
| Preparation Response（PRes）Message | DSのカード番号範囲、ACS・DSの有効なProtocol Version、3DS Method URL、またはこれらを取得するCard Range Data File URLを含むPReq応答。3DS Server内部の保存情報を更新できるようにする。 |
| Private key（秘密鍵） | 非対称暗号方式の一部で、所有者だけが知り、秘密に保つ鍵。 |
| Proof of authentication attempt | Attemptsを参照。 |
| Protocol Version | EMV 3-D Secureコンポーネント間のメッセージ相互運用性を定める。 |
| Public key（公開鍵） | 非対称暗号方式の一部で、全当事者に知られる鍵。 |
| Public key pair（公開鍵ペア） | 数学的に関連する公開鍵・秘密鍵の2つ。公開鍵（非対称）暗号アルゴリズムで用い、秘密を安全に交換することなく情報を安全に交換できる。 |
| Registered Application Provider Identifier（RID） | 決済システムに固有の登録アプリケーション提供者識別子。ISO 7816-5で定義され、その登録機関が発行する。5バイト。 |
| Responsive Design（レスポンシブデザイン） | 利用体験を改善するため、画面の寸法にWebページ内容を合わせる手法。画面幅に動的に適応する柔軟なグリッド、ブラウザー・画面に応じてCSSを変えるメディアクエリー、ビューポートに合わせて画像を拡縮する柔軟なメディアという3技術に基づく。 |
| Results Request（RReq）Message | 認証取引の結果を3DS Serverへ伝えるため、ACSがDSを経由して送るメッセージ。 |
