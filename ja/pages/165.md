### 5.9.7 3DS SDKによるCResのエラー処理

3DS SDKは、CResまたはErrorメッセージの検証を次のとおり処理する。以下のErrorメッセージはA.9節で定義する。

- 6.2.4.2節に従って正しく暗号学的検証・復号できない、または認識できないメッセージの場合、ACSにError Component = C、Error Code = 101（認識できない）または302（暗号学的検証・復号の失敗）を返す。
- 正しく暗号学的検証・復号・認識ができたCResは、表B.4と5.1.7節に従って検証する。存在するデータ要素が検証に失敗した場合、ACSにError Component = C、Error Code = 203を返す。必須データ要素が欠ける場合、ACSにError Component = C、Error Code = 201を返す。それ以外ではメッセージにエラーはない。
- Errorメッセージの場合、3DS Requestor Environmentにエラーの発生を通知する。

### 5.9.8 DSによるRReqのエラー処理

DSは、RReqの検証を次のとおり処理する。

認識できないメッセージの場合：

- ACSに、Error Component = D、Error Code = 101のErrorメッセージ（A.9節で定義）を返す。
- 特定の取引を識別できる場合、3DS Serverに5.9.8.1節のErrorメッセージを送る。

RReqの場合、表B.8と5.1.7節に従って検証する。存在するデータ要素が検証に失敗した場合、ACSにError Component = D、Error Code = 203のErrorメッセージ（A.9節で定義）を返す。
