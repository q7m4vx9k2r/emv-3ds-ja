### 1.5 Definitions

The following terms are used in this specification:

Table 1.3:  Definitions

| Term | Definition |
| --- | --- |
| 3DS Client | The consumer-facing component allowing consumer interaction with the<br>3DS Requestor for initiation of the EMV 3-D Secure protocol. |
| 3DS Integrator | An EMV 3-D Secure participant that facilitates and integrates the 3DS<br>Requestor Environment, and optionally facilitates integration between the<br>Merchant and the Acquirer. |
| 3DS Method | A scripting call provided by the 3DS Integrator that is placed on the 3DS<br>Requestor Website. Optionally used to obtain additional Browser<br>information to facilitate risk-based decisioning. |
| 3DS Requestor | The initiator of the EMV 3-D Secure Authentication Request. For example,<br>this may be a Merchant or a digital wallet requesting authentication within<br>a purchase flow. |
| 3DS Requestor App | An App on a Consumer Device that can process a 3-D Secure transaction<br>through the use of a 3DS SDK. The 3DS Requestor App is enabled<br>through integration with the 3DS SDK. |
| 3DS Requestor<br>Environment | The 3DS Requestor-controlled components (3DS Requestor App, 3DS<br>SDK, and 3DS Server) are typically facilitated by the 3DS Integrator.<br>Implementation of the 3DS Requestor Environment will vary as defined by<br>the 3DS Integrator. |
| 3DS Requestor Initiated<br>(3RI) | 3-D Secure transaction initiated by the 3DS Requestor for the purposes of<br>confirming that an account is still valid or for Cardholder authentication.<br>The first main use case being recurring transactions (TV subscriptions,<br>utility bill payments, etc.) where the Merchant wants to perform a payment<br>transaction to receive authentication data for each bill or a non-payment<br>transaction to verify that a subscription user still has a valid form of<br>payment. The second main use case is when the 3DS Requestor requests<br>Decoupled Authentication as a method to authenticate the Cardholder. |
| 3DS Requestor Website | Component that provides the website that requests Cardholder credentials<br>(whether on file or entered by Cardholder). |
| 3DS SDK | A component that interacts with the 3DS Requestor App. The 3DS SDK<br>performs functions related to 3-D Secure on behalf of the 3DS Server. |
| 3DS Server | Refers to the 3DS Integrator’s server or systems that handle online<br>transactions and facilitates communication between the 3DS Requestor<br>and the DS. |
| 3-D Secure (3DS) | An e-commerce authentication protocol that enables the secure<br>processing of payment, non-payment and account confirmation card<br>transactions. |
