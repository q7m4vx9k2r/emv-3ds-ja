### 5.9.5 ACS CReq Message Error Handling—01-APP

The ACS processes the validation of the CReq message or Error Message as follows:

- For a message, which the ACS cannot verify or decrypt correctly as defined in Section 6.2.4.3 or which the ACS cannot recognise, the ACS:

o Returns to the 3DS SDK an Error Message (as defined in Section A.9) with Error Component = A and Error Code = 101 (not recognised) or 302 (verification or decryption failure) using the secure link established in [Req 44].

o If a specific transaction can be identified, sends to the DS an RReq message as defined in Section 5.9.5.1.
