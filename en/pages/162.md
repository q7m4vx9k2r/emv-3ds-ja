The DS: If a message is in error and a specific transaction can be identified, the DS sends to the 3DS Server using the secure link established in [Req 12] for an App-based transaction, [Req 90] for a Browser-based transaction, or [Req 275] for a 3RI transaction, EITHER:

- an Error Message (as defined in Section A.9) with Error Component = D and the Error Code returned to ACS, OR

- an ARes message (as defined in Table B.2) with Transaction Status set to the appropriate value as defined by the specific DS.

- an ARes message (as defined in Table B.2) with Transaction Status set to the appropriate value as defined by the specific DS.
